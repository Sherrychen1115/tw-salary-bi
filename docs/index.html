圖 1　薪資與工時的關係

註：每個點是一個行業，數值是該行業受僱員工的每人每月平均。兩軸都不從 0 開始；軸的範圍固定為 109–114 年的全距，方便跨年比較。趨勢線是未加權的最小平方直線（每個行業算一點，不依員工人數加權）；相關不代表因果。

圖 2　各行業每人每月總薪資

註：依總薪資由高到低排序。總薪資 = 經常性薪資 + 非經常性薪資（獎金、加班費等），是名目金額，未扣除物價。各行業的數字是平均值，不能相加。

圖 3　各行業每人每月總工時

註：行業順序與圖 2 相同（依總薪資由高到低），所以點越往下越靠右，才代表高薪行業工時較短。橫軸不從 0 開始。總工時 = 正常工時 + 加班工時。

圖 4　109–114 年每人每月總薪資的變化

註：每條線是一個行業。名目薪資，未扣除物價，上升不等於購買力增加。縱軸不從 0 開始。直線標出目前選的年份。

圖 5　109–114 年每人每月總工時的變化

註：每條線是一個行業。年資料是全年各月的平均，工作日數每年不同，1–2 小時內的變動不宜過度解讀。縱軸不從 0 開始。直線標出目前選的年份。

報表原本的註解

  1. 本項統計涵蓋範圍自98年1月起新增「教育業（僅含教育輔助及其他教育業）」，自108年1月起新增「研究發展服務業」、「學前教育」及「社會工作服務業」。
  2. 因108年行業擴增幅度較大，為比較基礎一致，當年數據不與前一年資料進行比較。

限制

  • 報表中的「-」代表無資料，不是 0。「全年勞動報酬」和 5 個占勞動報酬比率的指標在原始檔中完全沒有數字，本頁沒有使用；實質薪資與兩個指數只有部分行業有值，也沒有使用。本頁用到的 8 個指標，每個行業每一年都有值。
  • 薪資是名目金額，未扣除物價。跨年比較時，薪資上升有一部分只是物價上漲。
  • 薪資和工時都是每人每月的平均值，不能跨行業相加，也不能直接取簡單平均當成全體的數字。本頁只做同一層級行業之間的比較：大類和大類比、中類和中類比，不把不同層級放在同一張圖。
  • 「餐館」「其他餐飲業」是中類「餐飲業」底下的小類，層級不同，所以沒有放進圖表。工業、服務業兩個部門只用來上色，不當作比較對象。
  • 相關係數把每個行業當成一點，沒有依員工人數加權，也只反映行業平均之間的關係，不能推論到個別勞工，更不代表因果。
  • 教育業不含小學以上各級公私立學校。
