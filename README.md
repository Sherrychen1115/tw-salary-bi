# 哪些行業留不住人？行業別進入率、退出率與薪資（民國 109–114 年）

把行政院主計總處「薪情平臺」匯出的 Excel 報表（寬格式），用 Python 轉成整齊的長格式 CSV，並以程式驗證轉換結果與原始檔一致，再做成一頁互動 BI 網頁。

網頁：<https://sherrychen1115.github.io/tw-salary-bi/>

## 資料來源

- 來源：行政院主計總處「薪情平臺」，行業別受僱員工薪資與工時統計
- 原始檔：`行政院主計總處統計資料/薪情平臺匯出資料_20261012000448.xlsx`（2026-10-12 匯出，未經修改）
- 資料性質：政府公開資料

## 期間與範圍

- 期間：民國 109–114 年（西元 2020–2025 年），年資料，共 6 年
- 指標：20 項（薪資、受僱員工人數、進入率／退出率、工時、指數、勞動報酬相關比率）
- 行業：115 個，分四層

| level | 個數 | 說明 |
|---|---|---|
| 部門 | 2 | 工業、服務業 |
| 大類 | 17 | 例如製造業、批發及零售業 |
| 中類 | 94 | 例如電子零組件製造業、銀行業 |
| 小類 | 2 | 餐館、其他餐飲業（上層是中類「餐飲業」） |

## 如何重跑

需要先安裝 [uv](https://docs.astral.sh/uv/)。程式都用 inline script metadata 宣告套件（openpyxl），不需要另外建立環境。

```
uv run scripts/etl_salary.py
uv run scripts/validate.py
uv run scripts/build_web_data.py
```

在本機看網頁要用網頁伺服器開（直接點開 index.html 會讀不到 data.json）：

```
uv run python -m http.server --directory docs
```

再開 <http://localhost:8000/>。

`validate.py` 每次會抽不同的 20 格；加上 `--seed 42` 可以固定抽樣結果。每次執行都會重寫 `data/validation_report.md`；全部通過時結束碼為 0。

## 資料欄位

**data/salary_long.csv**（每列：指標 × 年度 × 行業，共 20 × 6 × 115 = 13,800 列）

| 欄位 | 說明 |
|---|---|
| indicator | 指標名稱，例如 `每人每月總薪資` |
| unit | 單位，從原始指標名稱最後一組括號拆出，例如 `新臺幣元`、`人`、`%`、`小時`、`民國110年=100` |
| year_roc | 民國年，例如 `109` |
| year_ad | 西元年，例如 `2020` |
| industry | 行業名稱（保留原始檔寫法） |
| level | 行業層級：部門、大類、中類、小類 |
| parent | 上一層行業名稱；部門這一層留空 |
| value | 統計值；原始檔為「-」（無資料）時留空，不是 0 |

## 資料清理與驗證

### 處理了哪些髒資料

| 原始檔的狀況 | 處理方法 |
|---|---|
| 寬格式：一個行業一欄（115 欄），一個「指標 × 年度」一列 | 轉成長格式，一列只放一個數值（指標 × 年度 × 行業） |
| 表頭有 3 列（行業／總計／統計值），第 2、3 列每欄內容都一樣 | 行業名稱只取第 1 列；先確認第 2、3 列全是「總計」「統計值」，不是就報錯 |
| A 欄指標名稱是合併儲存格，每個指標只有第一個年度那列有字 | 往下填滿到同一指標的 6 個年度 |
| 指標名稱和單位黏在一起，例如 `每人每月總薪資(新臺幣元)` | 拆出最後一組括號當 `unit`，所以 `勞動生產力指數(產量)(民國110年=100)` 的指標名稱仍是 `勞動生產力指數(產量)` |
| 年度是文字 `109年` | 取出數字為 `year_roc`，加 1911 為 `year_ad` |
| 無資料寫成文字「-」（6,180 格） | `value` 留空，不寫成 0，避免被當成真的 0 拿去算平均或加總 |
| 表格下方有空白列和「註:」附註 | 讀到 A 欄以「註」開頭的列就停止，空白列略過 |
| 行業沒有任何層級標記（沒有縮排、沒有代碼），部門、大類、中類混在同一列 | 用 17 個大類名稱的清單判斷：兩個大類之間的欄位算前一個大類的中類，再標出 `level` 和 `parent`。清單寫在 `scripts/etl_salary.py`，表頭對不上時會直接報錯 |
| 「餐館」「其他餐飲業」是中類「餐飲業」再往下的一層，照上面的規則會被當成中類，使住宿及餐飲業的加總多算一倍 | 另外標成 `小類`，`parent` 設為「餐飲業」 |
| 行業名稱的頓號是「﹑」（U+FE51），不是常見的「、」（U+3001） | 不更動，保留原始寫法，才能和原始檔逐格比對；用名稱搜尋時要注意 |

原始 xlsx 只讀取、不寫回。

### 完全無資料的指標

下面 6 個指標在這份匯出檔中，6 個年度 × 115 個行業全部是「-」（各 690 格，共 4,140 格）。CSV 仍保留這些列，`value` 都是空的：

- 全年勞動報酬（新臺幣元）
- 經常性薪資占勞動報酬比率（%）
- 非經常性薪資占勞動報酬比率（%）
- 資遣費占勞動報酬比率（%）
- 職工福利金占勞動報酬比率（%）
- 其他福利金占勞動報酬比率（%）

另外 4 個指標只有部分行業有值（其餘 2,040 格無資料）：「每人每月實質總薪資」和「每人每月實質經常性薪資」只有部門、大類和礦業底下的 2 個中類；「經常性薪資指數」另有部分中類；「勞動生產力指數(產量)」只有工業底下的部分行業。

### 怎麼驗證

`scripts/validate.py` 自己重新讀一次 xlsx，不引用 ETL 的程式，結果寫在 [data/validation_report.md](data/validation_report.md)。

| 檢查 | 方法 |
|---|---|
| 列數 | 列數 = 指標數 × 年數 × 行業數（20 × 6 × 115 = 13,800），且（指標、年度、行業）不重複 |
| 逐格比對 | 隨機抽 20 格，回到原始 xlsx 的同一個儲存格比對；另外核對全表有值／無資料的格數，以及完全無資料的指標清單 |
| 層級加總 | 用「受僱員工人數」檢查中類加總 ≈ 大類、大類加總 ≈ 部門、小類加總 ≈ 中類。原始數字是四捨五入後的整數，容許差為子行業數；實際最大差 2 人 |

## 互動網頁

`docs/index.html` 用 `docs/data.json` 畫圖，回答兩個問題：哪些行業留不住人（退出率高）？低薪行業的流動是否比較高？

**先說結論（114 年，17 個大類）**

- 退出率最高的是支援服務業（每月 4.35%），最低的是電力及燃氣供應業（0.70%）
- 退出率與經常性薪資的相關係數：未加權 r = −0.62，依受僱員工人數加權 r = −0.64。兩種算法接近，低薪行業的退出率確實偏高，而且不是少數小行業造成的
- 17 個大類中有 13 個進入率高於退出率（人力擴張），淨進入率最高的是住宿及餐飲業（+0.33 個百分點）
- 這是行業平均之間的關係，不代表因果，也不能推論到個別勞工

**進入率、退出率怎麼讀**

- 單位是 %，是比率，不可跨行業相加或直接平均
- 年資料是全年 12 個月的平均（月平均），不是全年合計。原始報表沒有寫明，我用兩件事確認：
  1. 報表本身的數字：各行業「淨進入率 × 12」和受僱員工人數的年增減率大致相等。例如工業 110 年淨進入率 0.07 個百分點，乘以 12 是 0.84%，當年人數實際增加 0.89%
  2. 勞動部國際勞動統計[表 7-3「工業及服務業受僱員工月平均進退率」](https://statdb.mol.gov.tw/html/nat/113/7.表7-3.pdf)（資料來源：行政院主計總處「薪資與生產力統計月報」）：表上製造業 2020–2023 年的進入率 1.75、2.02、2.06、1.92，和這份報表 109–112 年的數字完全相同
- 所以退出率 2% 表示平均每個月約有 2% 的受僱員工離開
- 定義（當月進入或退出人次 ÷ 上月底受僱員工人數）是依調查的填報欄位整理的；我沒有找到官方名詞釋義的原文，網頁上也照實這樣寫

- 第一排是 4 張 KPI 卡片：退出率最高的行業、退出率最低的行業、淨進入率最高（人力擴張）的行業、退出率與經常性薪資的相關係數，各附與前一年相比的升降（▲▼）。比率比的是百分點，相關係數比的是 r 的差值；109 年是第一年，沒有前一年可比

- 6 個每個行業每一年都有值的指標：進入率、退出率、每人每月經常性薪資、每人每月總薪資、總工時、受僱員工人數
- 每人每月實質經常性薪資、實質總薪資：只收 6 年都有值的行業（2 個部門、17 個大類、礦業底下 2 個中類），網頁只在比較大類時使用
- 完全無資料的 6 個勞動報酬指標沒有放進 `data.json`

**自行計算的數字（不是官方統計）**

- 流動率（%）=（進入率 + 退出率）÷ 2
- 淨進入率（百分點）= 進入率 − 退出率；正值表示擴張，負值表示縮減
- 人數指數 = 各年受僱員工人數 ÷ 109 年人數 × 100
- 時薪（元/小時）= 每人每月總薪資 ÷ 每人每月總工時。兩個平均值相除的估算，不等於個別勞工實際的時薪；切到「實質」時分子改用實質總薪資
- 相關係數與趨勢線：未加權（每個行業算一點），或依受僱員工人數加權（加權最小平方、加權相關係數）

## 使用前請注意

- 13,800 格中有 6,180 格無資料，其中 6 個指標完全沒有數字（見「資料清理與驗證」），做圖表或篩選器時要先排除。
- 網頁預設顯示名目薪資，未扣除物價；跨年比較時可切到「實質」（只有大類）。
- 原始檔沒有「工業及服務業」全體合計欄；需要時可用受僱員工人數加總，但進入率、退出率這類比率，以及薪資、工時這類平均值，都不能直接相加或取簡單平均。
- 退出包含退休、資遣和契約期滿，不全是自願離職；季節性、短期人力多的行業進入率和退出率本來就都高。
- 行業名稱保留原始檔的寫法，其中的頓號是「﹑」（U+FE51）而不是常見的「、」（U+3001），用名稱比對或搜尋時要注意。
- 教育業不含小學以上各級公私立學校；研究發展服務業、學前教育、社會工作服務業自 108 年起才納入統計（見原始檔附註）。
